# Valentina y León: El Rescate de Violeta

Aventura cooperativa de 16 bits para dos hermanos. Valentina y León recorren la calle, la plaza y el castillo para rescatar a su hermana Violeta. Aquí nadie pelea: se avanza haciendo cariño y repartiendo comida a las mascotas guardianas (Arya, Cora, Dexter y Mila, la labradora negra) y resolviendo desafíos mentales en equipo.

**Jugar:** https://franciscovergarap.github.io/valentina-y-leon/

## Controles

| | Valentina (Jugador 1) | León (Jugador 2) |
|---|---|---|
| Moverse | `W` `A` `S` `D` | Flechas |
| Saltar | `Espacio` | `Enter` |
| Hacer cariño | `F` | `K` |
| Dar comida | `G` | `L` |

- `Esc`: pausa.
- En los desafíos: flechas o `A` / `D` para elegir, `Enter` o `Espacio` para responder y `H` para pedir una pista.
- Si juega una sola persona, León sigue y ayuda a Valentina automáticamente.

Se juega con el teclado de un computador. El avance se guarda en el navegador.

Todo el juego (gráficos, música y sonidos) está en un solo archivo, `index.html`.
